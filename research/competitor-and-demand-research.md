## 2. Competitor profiles

### mapgenie.io — the business-model reference (IGN-owned)
- 217+ game maps; ~7M monthly visits (SimilarWeb via HypeStat; SEMrush up to 13.4M). Global rank ~10,580.
- Features: 50–80+ categories per game, instant quicksearch, progress tracker ("mark as found"), user notes, multi-layer maps, iOS/Android apps syncing with web.
- Monetization: (1) display ads free users (~$1,640/day est.), (2) **Pro $9.99/yr** — all games incl. upcoming releases, no ads incl. apps, (3) mobile in-app purchases (Genshin app: 1M+ downloads, 4.2★).
- Weakness: no GTA 6 depth yet; generic portal; $9.99/yr caps ARPU.

### gtalens.com — best GTA-specific data model
- ~464K visits/mo (SEMrush, July 2026), avg session **12:14** (extremely sticky). US 30%, Austria 14%, UK.
- Features: 3 view modes (Game/Print/Satellite), category icon filters, click-marker → sidebar with tabular data (prices, incomes), "Watch video" guide links per location, "Mark as completed", prev/next navigation, accounts.
- Monetization: Patreon from ~$3/mo ("no ads, increased limits, multi-profiles") + display ads. Registration + Discord required for premium (friction).
- Weakness: dated UX, GTA 5/Online focus, no GTA 6 map, no mobile app, no route optimization.

### gtabase.com — content/SEO king, no interactive map
- ~1.7M monthly visits (cross-source agreement). 69–94K organic keywords. 66% mobile traffic (flagged poorly mobile-optimized). @TheGTABase ~100–122K X followers; "fan-page recognised by Rockstar Games".
- Features: news, evergreen guides, deep databases (vehicles, weapons, properties, missions, characters, cheats). GTA 6 map page = articles + static images only.
- Monetization: display ads + **VIP $4.99/mo or $35.88/yr** (ad removal + MyBase features). 50,000+ MyBase users.
- Weakness: **no true interactive map** — the single biggest gap.

### gta6map.co — vaporware
- Pre-launch landing page only (countdown). Roadmap: interactive map, progress tracking, smart search at launch; AI route planning + multiplayer sync in 2027. No traffic, no monetization, no email capture. Placeholder stock avatars = hastily assembled template.

### gta6map.io — early traction proof
- ~101K monthly visits (June 2026), "GTA 6 Interactive Map & Wiki". Display ads (~$17.89/day est.). No observable social.

### vicecitymethods.com — best map+editorial combo (GTA 6 specific)
- Working interactive map: story missions, collectibles (50 Leonida Memorabilia, 30 Everglades Stashes), Ammu-Nation, Pay 'n' Spray, safehouses, stunt jumps + landmark search. Wrapped in long-form region guides. News section ~2–3 articles/week, fastest editorial reactor to news cycle.
- Monetization: none observed yet (pre-monetization). No accounts/progress tracking.

### State of Leonida (map.stateofleonida.net) — best pre-launch fan map
- ~1,600 markers triangulated from trailers/screenshots/leaks vs real Florida geography. Per-location trailer video clips. Location-guessing game + leaderboard. v13 by "YANIS" via GTA Mapping Community Discord. Press coverage (GamingBible, G2A, Notebookcheck, Insider Gaming).
- Monetization: none (volunteer). Single-maintainer risk. No accounts/tracking.

### gtatracker.gg — closest to target vision (bonus find)
- Interactive map + entity database (GTA 5 DB: 1,430 items, 12 categories: vehicles, weapons, properties, collectibles, cosmetics, radio stations) + guides + 100% completion tracker + community submissions (editor-reviewed) + compare tool (cars/guns side-by-side) + tier lists + **embeddable widgets** (free embeds = backlink engine) + news labeled official vs unconfirmed.
- No route planner, no pro tier observed.

## 4. Top 10 user pain points (ranked by frequency)

1. **Wrong / outdated locations — the #1 trust killer.** One wrong pin destroys trust in all pins. Community publicly dissects maps below ~95–98% accuracy. Users post photo proof of errors.
2. **Confirmed-vs-speculation confusion.** Viewers have been burned by fake maps. "Confirmed-only" is now a trust differentiator; State of Leonida is praised for certainty labeling.
3. **Surprise paywall on progress tracking (100-marker cap).** Map Genie's cap generates the most anger ("Scam and a rip-off"). Nuance: paying users say $9.99/yr is *cheap* — the anger is about the **surprise**, not the price. A GitHub project exists solely to bypass the cap.
4. **Intrusive ads on guide sites, especially mobile.** GTA Wiki left Fandom (Mar 2026) over "increasingly aggressive use of ads"; 60%+ of guide visitors are logged-out mobile users.
5. **Login / account / progress-save failures.** "Failed to mark location" errors; lost marked state on restart; GTALens premium requires registration + Discord (friction on the two features users care about most).
6. **Crashes, blank screens, broken rendering.** Map Genie app: blank screen with ad at bottom; tile scramble on zoom.
7. **Stale data / slow updates after content drops.** "Please do an update… why so late."
8. **Mobile / second-screen UX friction.** Companion apps are actively hated ("the age of companion apps is over"). Users want web-based mobile map, no install, floating/second-screen friendly.
9. **No multi-floor / underground layers.** Relevant: GTA 6's Vice City will have dense interiors.
10. **Fragmented knowledge — no canonical reference.** Community map lives in a 510-page forum thread + Discord + 3 competing fan maps. No single stable reference.

## 5. Top 10 feature demands (ranked)

1. **Progress tracking — mark-as-found, persistent, FREE by default.** The single most demanded feature. Paywalling it is the #1 resentment generator.
2. **Certainty/source labels on every pin.** "Spotted in Trailer 2 @ 1:47" badges; Confirmed / Likely / Speculation tiers.
3. **Category filters + instant search with fly-to results.** Without filters the map is "a noisy mess".
4. **Google-Maps-like UX.** Smooth pan/zoom, no hard zoom limit, gesture controls.
5. **Per-pin detail: video guides, screenshots, descriptions.** Visual proof expected.
6. **Multiple map views** (atlas / satellite / road; 3D interest).
7. **Personal notes on the map.**
8. **Shareable deep-links** (`/map?lat=X&lng=Y&zoom=Z&layers=...` + "Copy Link").
9. **Money guides** (best methods, profit-per-hour, first-10-hours, robbery targets with estimated take on map).
10. **Vehicle spawn locations + rarity tiers.**

Tier 2: 100% completion checklist; real-life location comparisons; community submissions with "Community Verified" badges; mobile bottom-sheet UI; multilingual UI (Spanish/Portuguese volunteers already appeared); daily/rotating collectible support.

## 9. Distribution insight

Map tools don't win on owned social — discovery flows through **Google + press + big GTA YouTubers** (map-theory Shorts doing 400K+ views). Only gtabase has a real owned audience (100K+ X). Launch distribution = YouTuber partnerships + press, not just owned social.

## 10. Update cadence (pace-setters to beat)

- vicecitymethods: articles every 3–7 days — fastest editorial reactor.
- gtatracker.gg: data updated within hours ("2 hours ago") — fastest data reactor.
- gtabase: staff-powered, regular refreshes.
- **Implication:** the launch-week speed crown is contestable. A "verified within hours" pipeline + timestamped updates ("verified 2h after launch") is itself a differentiator.

## 11. Strategic synthesis → MVP implications

**The winning formula (evidence-backed):**
> A GTALens-grade interactive Leonida map that weaponizes **trust** (confirmed-only badges with trailer timestamps, clear speculation labeling), keeps **progress tracking + notes FREE by default**, ships **fast mobile-web UX (explicitly not an app)**, and launches with a **72-hour verification sprint** on Nov 19.

**The combo nobody has:** interactive map + per-entity database pages + editorial guides, all interlinked (map pin ↔ entity page ↔ guide). gtatracker.gg is the closest — primary benchmark.

**MVP must-haves (from pain points):**
1. Accuracy-first data model with certainty badges (Confirmed / Likely / Speculation + source timestamp)
2. Free progress tracking (no surprise caps — state limits upfront or have none)
3. Category filters + instant search
4. Mobile-first web map (bottom-sheet detail UI, fast tiles)
5. Per-pin detail: screenshots + video embeds
6. Community submissions with "Community Verified" badges + voting
7. Shareable deep-links
8. Light, non-intrusive ads (learn from Fandom exodus)

**MVP must-avoids:**
- Surprise paywalls on the tracking loop
- Required login for basic tracking (localStorage-first, optional account sync)
- Companion app (hated) — mobile web instead
- Speculation presented as fact
- Heavy ad layouts on mobile

**Monetization order:** display ads (day 1) → affiliate (pre-order/hardware) → Pro tier priced ABOVE the $9.99/yr anchor ($29/yr: route planner + video guides + priority data — no direct competitor) → sponsored placements later.

**Pre-launch moat builders:** email capture (nobody does it), programmatic entity pages (500–1000 pages: cars/locations/stores/missions), trailer-based map live now, YouTuber partnerships, press-ready "confirmed-only" positioning.
